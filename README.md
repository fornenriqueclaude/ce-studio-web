# C&E Studio — Web

Kit de arranque para construir la web con Claude Code.

## Cómo empezar
1. Instala Node.js 20 o superior y la extensión de Claude Code en VS Code.
2. Abre esta carpeta en VS Code.
3. Abre Claude Code y pega el prompt de `PROMPT_INICIAL.md`.
4. Revisa y aprueba cada fase.

## Contenido
- `CLAUDE.md` — reglas del proyecto que Claude Code lee automáticamente.
- `docs/brief.md` — negocio, secciones y textos.
- `docs/design.md` — dirección visual, parallax y animaciones.
- `docs/legal.md` — aviso legal, privacidad y cookies.
- `public/brand/` — logo sin fondo en varias versiones + favicons.
